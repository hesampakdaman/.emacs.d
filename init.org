* introduction
This Emacs configuration will be tangled to =init.el= inside Emacs'
configuration directory -- usually =~/.emacs.d= -- with one exception:
the code in subsection [[early-init]] below will be tangled to the
same directory as =early-init.el=.

This will make sure that the tangled file has lexical binding.

* early-init
:PROPERTIES:
:header-args: :tangle (concat user-emacs-directory "early-init.el")
:END:
#+begin_src emacs-lisp
  ;; -*- lexical-binding: t; -*-

  ;; Raise the GC threshold so Emacs doesn't collect garbage while
  ;; loading the config. It is lowered again in `after-init-hook' below.
  (setq gc-cons-threshold (* 100 (expt 10 6)) ; 100MB
        gc-cons-percentage 0.8)

  ;; Every `load' consults `file-name-handler-alist' (TRAMP, compressed
  ;; files, ...). Empty it during startup and restore it afterwards.
  (defvar startup/file-name-handler-alist file-name-handler-alist)
  (setq file-name-handler-alist nil)

  ;; Lower garbage collection threshold after init to minimize impact
  ;; of GC during normal use. Reset file-name-handler-alist.
  (add-hook 'after-init-hook
            (lambda ()
              (setq gc-cons-threshold (* 50 (expt 10 6)) ; 50MB
                    gc-cons-percentage 0.1
                    file-name-handler-alist startup/file-name-handler-alist)))

  ;; *scratch* starts in fundamental-mode, so lisp-interaction-mode
  ;; isn't loaded during startup
  (setq initial-major-mode 'fundamental-mode)

  ;; don't resize the frame when the font, tool bar etc. change size;
  ;; the window manager decides the frame size
  (setq frame-inhibit-implied-resize t)

  ;; no splash screen
  (setq inhibit-splash-screen t
        inhibit-startup-screen t
        inhibit-startup-message t
        inhibit-startup-buffer-menu t)

  ;; resize frames by pixel rather than whole characters, so tiled
  ;; frames fill the space the window manager gives them
  (setq frame-resize-pixelwise t)

  ;; set these early to reduce flickering/resizing on startup
  (scroll-bar-mode -1)
  (tool-bar-mode -1)
  (menu-bar-mode -1)

  ;; No title bar or WM decorations. The 15px internal border is
  ;; padding around the frame's edge, and `drag-internal-border' lets
  ;; us resize the frame by dragging that border instead.
  (dolist (frame-option
           '((undecorated . t) (internal-border-width . 15) (drag-internal-border . 5)))
    (add-to-list 'default-frame-alist frame-option))
#+end_src

* foundation
Settings that the rest of the configuration builds on: package

** package management

*** use-package
#+begin_src emacs-lisp
  (require 'use-package-ensure)
  (setq use-package-always-defer t     ; lazy-load unless :demand or :defer N
        use-package-always-ensure t)   ; install missing packages

  ;; `use-package-ensure-elpa' requires package.el for every :ensure,
  ;; which costs ~60ms at startup even when nothing needs installing.
  ;; Skip it for packages the quickstart already activated and for
  ;; built-ins; anything else falls through and gets installed.
  (defun hesam--use-package-ensure (name args state &optional no-refresh)
    (let ((pkg (use-package-as-symbol name)))
      (unless (and (equal args '(t))
                   (or (memq pkg package-activated-list)
                       (package-built-in-p pkg)))
        (use-package-ensure-elpa name args state no-refresh))))
  (setq use-package-ensure-function #'hesam--use-package-ensure)

  ;; Not demanded: startup activates packages from the quickstart file
  ;; without loading package.el, and `package-installed-p' (used by
  ;; :ensure) is autoloaded from the lighter package-activate.el. This
  ;; config runs once package.el is needed, e.g. to install a package.
  (use-package package
    :config
    (setq package-native-compile t   ; native-compile at install, not on first load
          package-quickstart t)      ; keep package-quickstart.el up to date
    (add-to-list 'package-archives '("melpa" . "https://melpa.org/packages/")))
#+end_src

*** system-pkg
Declare system (Arch, via =yay=) dependencies next to the Emacs
packages that need them. =(system-pkg ripgrep :exe rg)= queues
=ripgrep= for installation if =rg= isn't on =PATH= and the package
isn't installed; =M-x system-pkg-install-queued= then installs
everything queued in one =yay= call. The macro does nothing unless
=system-pkg-mode= is on.
#+begin_src emacs-lisp
  (defgroup system-pkg nil
    "Ensure system packages are installed."
    :group 'external)

  (defcustom system-pkg-install-command
    (lambda (pkgs)
      (format "yay -S --noconfirm --needed %s"
              (mapconcat #'shell-quote-argument pkgs " ")))
    "Function that takes a list of PKGS and returns a shell command string."
    :type 'function
    :group 'system-pkg)

  (defcustom system-pkg-installed-p
    (lambda (pkg-name)
      (eq 0 (call-process "yay" nil nil nil "-Qi" pkg-name)))
    "Function that returns non-nil if PKG is installed."
    :type 'function
    :group 'system-pkg)

  (defvar system-pkg--queue nil)

  (defun system-pkg--name (x)
    (cond
     ((symbolp x) (symbol-name x))
     ((stringp x) x)
     (t (error "Expected symbol or string, got: %S" x))))

  (cl-defmacro system-pkg (pkg &key exe)
    "Ensure PKG is available, queuing it for installation if necessary.

  PKG is the name of the system package to install.

  EXE, if provided, specifies the executable to check for with
  `executable-find`. Defaults to PKG.

  A package is considered present if either the executable is found
  in PATH or `system-pkg-installed-p` reports it as installed."
    (declare (indent 1))
    `(when system-pkg-mode
       (let ((pkg-name (system-pkg--name ',pkg))
             (exe-name (system-pkg--name ',(or exe pkg))))
         (unless (or (executable-find exe-name)
                     (funcall system-pkg-installed-p pkg-name))
           (cl-pushnew pkg-name system-pkg--queue :test #'string=)))))

  (defun system-pkg-install-queued ()
    (interactive)
    (when system-pkg--queue
      (let ((pkgs (delete-dups (reverse system-pkg--queue))))
        (setq system-pkg--queue nil)
        (async-shell-command
         (funcall system-pkg-install-command pkgs)
         "*system-pkg-install*"))))

  (define-minor-mode system-pkg-mode
    "Toggle queued system package support."
    :global t
    :lighter " SysPkg")
#+end_src

** performance and startup
Reduce the cost of bidirectional text on every redisplay. Reordering
stays on, so right-to-left text still displays correctly, but
paragraphs are assumed left-to-right and the bracket-pair algorithm is
skipped. We also defer syntax-highlighting while typing, so scrolling
and typing may feel smoother.
#+begin_src emacs-lisp
  (use-package emacs
    :init
    ;; Read subprocess output in chunks of up to 4MB. Language servers
    ;; send large JSON responses, which otherwise arrive in many reads.
    (setq read-process-output-max (* 4 1024 1024))
    ;; Wait 0.1s (default 0.5s) of idle time before updating things
    ;; that follow point, so they feel snappier.
    (setq idle-update-delay 0.1)
    ;; cheaper bidi: paragraphs assumed LTR, skip bracket-pair algorithm
    (setq-default bidi-display-reordering t
                  bidi-paragraph-direction 'left-to-right)
    (setq bidi-inhibit-bpa t)
    ;; defer fontification while typing
    (setq redisplay-skip-fontification-on-input t))
#+end_src

It's a good idea to be aware of Emacs' startup time. In case any new setting has dramatic effect on it, this should hopefully make you aware.
#+begin_src emacs-lisp
  (use-package emacs
    :demand t
    :preface
    (defun hesam--display-startup-time ()
      (message "Emacs loaded in %s seconds with %d packages active. Happy hacking!"
               (emacs-init-time "%.2f")
               (length package-activated-list)))
    :hook (emacs-startup . hesam--display-startup-time))
#+end_src

* general behaviour
Global settings that affect Emacs as a whole: files, buffers, help

** autosave and backups
Saves all backups to user's Emacs directory and in addition creates
numbered backups. First things first, we create autosave and backup
directory where we put autosaves and backups respectively.
#+begin_src emacs-lisp
  (defcustom hesam-autosave-directory (expand-file-name "autosave/" user-emacs-directory)
    "Directory where auto-save files are put."
    :type 'directory
    :group 'hesam)

  (defcustom hesam-backup-directory (expand-file-name "backup/" user-emacs-directory)
    "Directory where backup files are put."
    :type 'directory
    :group 'hesam)
#+end_src

Of course we need to make sure these directories exist.
#+begin_src emacs-lisp
  (dolist (dir (list hesam-autosave-directory hesam-backup-directory))
    (unless (file-directory-p dir)
      (make-directory dir)))
#+end_src

Use the directory for backups. We keep numbered backups (=file.~1~=,
=file.~2~=, ...), up to the newest 1000 versions of each file.
#+begin_src emacs-lisp
  (setq backup-directory-alist `((".*" . ,hesam-backup-directory))
        version-control t           ; Use version numbers for backups.
        kept-new-versions 1000	  ; Number of newest versions to keep.
        kept-old-versions 0         ; Number of oldest versions to keep.
        delete-old-versions t ; Don't ask to delete excess backup versions.
        backup-by-copying t)  ; Copy all files, don't rename them.
#+end_src

But Emacs only makes a backup on the first save after visiting a file.
We want one on every save. Emacs tracks this with the buffer-local
flag =buffer-backed-up=, so we reset it before each save and Emacs
makes a new backup every time.
#+begin_src emacs-lisp
  (defun force-backup-of-buffer ()
    (setq buffer-backed-up nil))
  (add-hook 'before-save-hook  'force-backup-of-buffer)
#+end_src

We also keep auto-save files in the autosave directory instead of next
to the files. The =t= makes the name unique by encoding the file's full
path, so two files named =init.el= don't collide.
#+begin_src emacs-lisp
  (setq auto-save-file-name-transforms
	`((".*" ,hesam-autosave-directory t)))
#+end_src

** calendar and time
Calendar settings: weeks start on Monday, European date order, a
24-hour clock and ISO week numbers. The location is also used by
=solar= for sunrise and sunset, which the [[matugen]] light/dark switch
relies on.
#+begin_src emacs-lisp
  (use-package calendar
    :init
    ;; 1. Location & Solar (Stockholm)
    (setq calendar-latitude 59.33
          calendar-longitude 18.06
          calendar-location-name "Stockholm, Sweden")

    ;; 2. Date & Week Formatting (EU Standard)
    (setq calendar-week-start-day 1
          calendar-date-style 'european
          calendar-date-display-form
          '((if dayname (concat dayname ", ")) day " " monthname " " year))

    ;; 3. Time & Week Number Display
    ;; `calendar-intermonth-text' shows the ISO week number ("W41") to
    ;; the left of each week in M-x calendar.
    (setq calendar-time-display-form '(24-hours ":" minutes)
          display-time-24hr-format t
          display-time-day-and-date nil
          display-time-default-load-average nil
          calendar-intermonth-text
          '(propertize
            (format "W%2d"
                    (car (calendar-iso-from-absolute
                          (calendar-absolute-from-gregorian (list month day year)))))
            'font-lock-face 'calendar-iso-week-face)))
#+end_src

* keybindings
Most bindings are not defined here. Instead we bind keys where the
package they belong to is configured, using =use-package= and its
=:bind= keyword. This section holds the bindings that don't belong to
any one package.

** unbinding and disabling

We want to unbind default bindings that aren't useful to us, such as suspending.

    :init
    (global-unset-key (kbd "C-z"))
    (global-unset-key (kbd "C-x C-z")))
#+end_src

as disabled makes Emacs ask for confirmation if they are ever run, for

* minibuffer and completion
The minibuffer stack (vertico, orderless, marginalia, consult, embark)
comes first, followed by completion inside buffers (corfu, cape,
dabbrev, tempel).

** vertico
Minibuffer completion system. It will display a vertical scrolling
minibuffer for commands like =M-x= or =C-x C-f=.
#+begin_src emacs-lisp
  (use-package vertico
    :demand t
    :init
    (vertico-mode)
    :config
    ;; In-buffer completion where corfu isn't active (e.g. M-: in the
    ;; minibuffer) shows candidates in Vertico via
    ;; `consult-completion-in-region'. Fall back to the default if
    ;; Vertico is turned off.
    (setq completion-in-region-function
          (lambda (&rest args)
            (apply (if vertico-mode
                       #'consult-completion-in-region
                     #'completion--in-region)
                   args))))
#+end_src

** orderless
Provides a completion style that matches space-separated components
in any order. If we do =C-x C-f= and have two files
=languages-and-modes.org= and =general.org= then the search string =g l=
matches both, since the order of the search words does not matter.

File names keep =partial-completion= first, so =/u/s/l= expands to
=/usr/share/locale= and so on. =completion-category-defaults= is cleared
so Emacs' per-category defaults don't override orderless elsewhere.
#+begin_src emacs-lisp
  (use-package orderless
    :demand t
    :config
    (setq completion-styles '(orderless basic)
          completion-category-defaults nil
          completion-category-overrides '((file (styles . (partial-completion))))))
#+end_src

** embark
=embark-act= (=C-;=) offers actions on the thing at point or the
current minibuffer candidate: open, rename, delete, copy, and so on.
=embark-consult= adds live previews in =embark-collect= buffers.

Setting =prefix-help-command= means that =C-h= after an incomplete
prefix (e.g. =C-x C-h=) lists that prefix's bindings with completion,
instead of opening a help buffer.
#+begin_src emacs-lisp
  (use-package embark
    :init
    (setq prefix-help-command #'embark-prefix-help-command)
    :bind
    (("C-;" . embark-act)
     ("C-h B" . embark-bindings))
    :config
    ;; no mode line in Embark's collect buffers
    (add-to-list 'display-buffer-alist
                 '("\\`\\*Embark Collect \\(Live\\|Completions\\)\\*"
                   nil
                   (window-parameters (mode-line-format . none)))))

  (use-package embark-consult
    :hook (embark-collect-mode . consult-preview-at-point-mode))
#+end_src
By default =embark= will show a preview window. We don't want that and instead prefer a =which-key= like popup. We can do that by adding the following to our config, directly copied from [[https://github.com/oantolin/embark/wiki/Additional-Configuration#use-which-key-like-a-key-menu-prompt][the wiki]].
#+begin_src emacs-lisp
  (defun embark-which-key-indicator ()
    "An embark indicator that displays keymaps using which-key.
  The which-key help message will show the type and value of the
  current target followed by an ellipsis if there are further
  targets."
    (lambda (&optional keymap targets prefix)
      (if (null keymap)
          (which-key--hide-popup-ignore-command)
        (which-key--show-keymap
         (if (eq (plist-get (car targets) :type) 'embark-become)
             "Become"
           (format "Act on %s '%s'%s"
                   (plist-get (car targets) :type)
                   (embark--truncate-target (plist-get (car targets) :target))
                   (if (cdr targets) "…" "")))
         (if prefix
             (pcase (lookup-key keymap prefix 'accept-default)
               ((and (pred keymapp) km) km)
               (_ (key-binding prefix 'accept-default)))
           keymap)
         nil nil t (lambda (binding)
                     (not (string-suffix-p "-argument" (cdr binding))))))))

  (setq embark-indicators
    '(embark-which-key-indicator
      embark-highlight-indicator
      embark-isearch-highlight-indicator))

  (defun embark-hide-which-key-indicator (fn &rest args)
    "Hide the which-key indicator immediately when using the completing-read prompter."
    (which-key--hide-popup-ignore-command)
    (let ((embark-indicators
           (remq #'embark-which-key-indicator embark-indicators)))
        (apply fn args)))

              :around #'embark-hide-which-key-indicator)

Commands for the =cliphist= clipboard history (Wayland), all under the
=C-c y= prefix.
- =C-c y y= :: insert the most recent cliphist entry. With =C-u=, pick
  any entry from the history.
- =C-c y c= / =C-c y x= :: copy / cut the region to the system clipboard
  with =wl-copy=, so cliphist records it.
#+begin_src emacs-lisp
  (use-package emacs
    :bind (("C-c y y" . hesam-cliphist-select)
           ("C-c y c" . hesam-cliphist-copy)
           ("C-c y x" . hesam-cliphist-cut))
    :preface
    (defun hesam-cliphist-copy ()
      (interactive)
      (unless (use-region-p)
        (user-error "No active region"))
      (call-process-region (region-beginning) (region-end) "wl-copy"))

    (defun hesam-cliphist-cut ()
      (interactive)
      (unless (use-region-p)
        (user-error "No active region"))
      (let ((text (buffer-substring-no-properties
                   (region-beginning)
                   (region-end))))
        (kill-region (region-beginning) (region-end))
        (with-temp-buffer
          (insert text)
          (call-process-region (point-min) (point-max) "wl-copy"))))

    (defun hesam-cliphist--entries ()
      (mapcar
       (lambda (line)
         (cons (replace-regexp-in-string "^[0-9]+[[:space:]]+" "" line)
               line))
       (process-lines "cliphist" "list")))

    (defun hesam-cliphist--decode (raw)
      (with-temp-buffer
        (insert raw)
        (call-process-region (point-min) (point-max) "cliphist" t t nil "decode")
        (buffer-string)))

    (defun hesam-cliphist-select--first ()
      (let* ((entries (hesam-cliphist--entries))
             (raw (cdar entries)))
        (when raw
          (let ((text (hesam-cliphist--decode raw)))
            (insert text)
            (kill-new text)))))

    (defun hesam-cliphist-select--list ()
      (let* ((entries (hesam-cliphist--entries))
             (vertico-sort-function nil)
             (choice (completing-read "cliphist: " entries nil t)))
        (when choice
          (let ((raw (cdr (assoc choice entries))))
            (when raw
              (let ((text (hesam-cliphist--decode raw)))
                (insert text)
                (kill-new text)))))))

    (defun hesam-cliphist-select (arg)
      (interactive "P")
      (if arg
          (hesam-cliphist-select--list)
        (hesam-cliphist-select--first))))

** hyprland integration
One set of keys moves focus both between Emacs windows and between
Hyprland windows. Hyprland binds =SUPER+h/j/k/l= to
=emacsclient -e "(hesam/windmove-or-hyprland 'left)"= and so on (see
=~/.config/hypr/hyprland.lua=). If Emacs is focused, we move to the
neighbouring Emacs window, and at the edge of the frame we hand over
to Hyprland. If another program is focused, we just ask Hyprland to
move focus.

=hyprctl= needs =HYPRLAND_INSTANCE_SIGNATURE= in its environment. The
Emacs daemon can start before Hyprland, and then lacks the variable,
so we look it up with =hyprctl instances= the first time we need it.
#+begin_src emacs-lisp
  (defun hesam/windmove-or-hyprland (dir)
    "If focused window is Emacs, try to move using windmove.
  If that fails or not in Emacs, fallback to Hyprland movefocus.
  DIR should be one of the symbols: 'left, 'right, 'up, or 'down."
    (hesam/hyprland-ensure-env)
    (if (hesam/hyprland-emacs-window-p)
        (hesam/hyprland-windmove-or-fallback dir)
      (hesam/hyprland-move-focus dir)))

  (defun hesam/hyprland-emacs-window-p ()
    "Return t if the currently focused Hyprland window is Emacs."
    (let* ((json (shell-command-to-string "hyprctl activewindow -j"))
           (class (when (string-match "\"class\": \"\\([^\"]+\\)\"" json)
                    (match-string 1 json))))
      (string= class "emacs")))

  (defun hesam/hyprland-windmove-or-fallback (dir)
    "Try to move focus in Emacs in direction DIR using windmove.
  If that fails (no window), fallback to Hyprland's movefocus.
  DIR should be one of the symbols: 'left, 'right, 'up, or 'down."
    (let ((fn (pcase dir
                ('left  #'windmove-left)
                ('right #'windmove-right)
                ('up    #'windmove-up)
                ('down  #'windmove-down)
                (_ (error "Invalid windmove direction: %s" dir)))))
      (condition-case nil
          (funcall fn)
        (user-error
         (hesam/hyprland-move-focus dir)))))

  (defun hesam/hyprland-move-focus (dir)
    "Ask Hyprland to move focus in direction DIR."
    (let ((hypr-dir (symbol-name dir)))
      (call-process "hyprctl" nil 0 nil "dispatch"
                    (format "hl.dsp.focus({ direction = \"%s\" })" hypr-dir))))

  (defun hesam/hyprland-ensure-env ()
    "Set HYPRLAND_INSTANCE_SIGNATURE using the currently running Hyprland instance.
  Uses `hyprctl instances` to get the active signature."
    (unless (getenv "HYPRLAND_INSTANCE_SIGNATURE")
      (when-let* ((output (ignore-errors (shell-command-to-string "hyprctl instances")))
                  (match (string-match "^instance \\([^\n:]+\\):" output))
                  (sig (match-string 1 output)))
        (setenv "HYPRLAND_INSTANCE_SIGNATURE" sig))))
#+end_src

* appearance
Fonts, themes and the mode-line. Some appearance settings live closer
to what they affect, e.g. the collapsed-text symbol of =hideshow= under
[[programming]].

** fonts
The font size follows the monitor's DPI. For each frame we compute the
DPI from the monitor's size in pixels and millimetres, and pick a base
point size from it. Fonts are reapplied when a frame is created, when
it moves (e.g. to another monitor) and when focus changes.

=hesam/zoom-in=, =hesam/zoom-out= and =hesam/zoom-reset= adjust an offset on
top of the DPI-based size, for all frames. With =repeat-mode=, after
one zoom command we can keep pressing =+= / =-= / =0=.
#+begin_src emacs-lisp
  (defcustom hesam-default-font-family "JetBrainsMono Nerd Font"
    "Default font family."
    :type 'string
    :group 'hesam)

  (defvar hesam/zoom-offset 0
    "Manual font size adjustment in 1/10pt units, persists across DPI changes.")

  (defun hesam/display-dpi (frame)
    "Return the horizontal DPI of FRAME."
    (let* ((attrs (frame-monitor-attributes frame))
           (geom  (alist-get 'geometry attrs))
           (mm    (alist-get 'mm-size attrs))
           (px-w  (nth 2 geom))
           (mm-w  (car mm)))
      (when (and mm-w (> mm-w 0))
        (* (/ (float px-w) mm-w) 25.4))))

  (defun hesam/dpi-base-pt (dpi)
    "Return a base point size tuned for DPI."
    (cond
     ((< dpi 110) 11)   ; typical 1080p / low DPI
     ((< dpi 140) 12)   ; 1440p monitors
     ((< dpi 180) 13)   ; higher DPI
     (t           14))) ; very high DPI (HiDPI / 4K laptops)

  (defun hesam/set-font-from-dpi (frame)
    "Set FRAME font size based on monitor DPI."
    (let* ((dpi    (or (hesam/display-dpi frame) 96))
           (base   (hesam/dpi-base-pt dpi))
           (height (+ (* base 10) hesam/zoom-offset))) ; 1/10pt units
      (set-face-attribute 'default frame
                          :family hesam-default-font-family
                          :weight 'regular
                          :height height)
      ;; fixed-pitch: same metrics as default, kept as a distinct face
      (set-face-attribute 'fixed-pitch frame
                          :family hesam-default-font-family
                          :weight 'regular
                          :height height)
      (set-face-attribute 'fixed-pitch-serif frame
                          :family hesam-default-font-family
                          :weight 'regular
                          :height height)
      ;; variable-pitch: distinct face, just share the same family/size
      (set-face-attribute 'variable-pitch frame
                          :family hesam-default-font-family
                          :weight 'regular
                          :height height)))

  (defun hesam/apply-font-to-frame (frame)
    "Apply Hesam font configuration to FRAME."
    (with-selected-frame frame
      (hesam/set-font-from-dpi frame)))

  (defun hesam/apply-to-all-frames ()
    "Refresh font settings for every open frame."
    (mapc #'hesam/apply-font-to-frame (frame-list)))

  (defun hesam/zoom-in ()
    "Increase font size across all frames."
    (interactive)
    (setq hesam/zoom-offset (+ hesam/zoom-offset 10))
    (hesam/apply-to-all-frames))

  (defun hesam/zoom-out ()
    "Decrease font size across all frames."
    (interactive)
    (setq hesam/zoom-offset (- hesam/zoom-offset 10))
    (hesam/apply-to-all-frames))

  (defun hesam/zoom-reset ()
    "Reset font size to DPI default across all frames."
    (interactive)
    (setq hesam/zoom-offset 0)
    (hesam/apply-to-all-frames))

  (defvar hesam-zoom-repeat-map
    (let ((map (make-sparse-keymap)))
      (define-key map (kbd "=") #'hesam/zoom-in)
      (define-key map (kbd "+") #'hesam/zoom-in)
      (define-key map (kbd "-") #'hesam/zoom-out)
      (define-key map (kbd "0") #'hesam/zoom-reset)
      map)
    "Keymap to repeat hesam zoom commands.")

  (put #'hesam/zoom-in    'repeat-map 'hesam-zoom-repeat-map)
  (put #'hesam/zoom-out   'repeat-map 'hesam-zoom-repeat-map)
  (put #'hesam/zoom-reset 'repeat-map 'hesam-zoom-repeat-map)

  (define-minor-mode hesam-dpi-mode
    "DPI-aware font auto-scaling."
    :global t
    :group 'hesam
    (if hesam-dpi-mode
        (progn
          (add-hook 'after-make-frame-functions #'hesam/apply-font-to-frame)
          (add-hook 'move-frame-functions       #'hesam/apply-font-to-frame)
          (add-function :after after-focus-change-function #'hesam/apply-to-all-frames)
          (hesam/apply-to-all-frames))
      (remove-hook 'after-make-frame-functions #'hesam/apply-font-to-frame)
      (remove-hook 'move-frame-functions       #'hesam/apply-font-to-frame)
      (remove-function after-focus-change-function #'hesam/apply-to-all-frames)))

  (hesam-dpi-mode 1)
#+end_src

** matugen
=matugen= generates a colour scheme from the current wallpaper and
applies it system-wide through templates. Emacs takes part in two
ways.

*** dark mode toggle
Switch the whole desktop between light and dark at sunrise and sunset.
Sunset is moved earlier by =hesam-matugen-sunset-offset= minutes. Times
come from =solar=, using the location set in [[calendar and time]].
=hesam-matugen-mode= runs a timer that fires at the next sunrise or
sunset, applies the matching mode and re-arms itself. At startup we
also correct the mode if the system (as reported by =darkman=) is
wrong for the time of day. The last applied mode is saved with
=customize=. =M-x hesam-matugen-toggle= switches by hand.
#+begin_src emacs-lisp
  (defcustom hesam-matugen-current-wallpaper-path "~/.local/state/wallpaper_path"
    "Path to the file containing the current wallpaper path."
    :type 'file
    :group 'hesam)

  (defcustom hesam-matugen-darkmode-state 'dark
    "Last applied Matugen mode."
    :type '(choice (const light) (const dark))
    :group 'hesam)

  (defcustom hesam-matugen-sunset-offset 35
    "Minutes before mathematical sunset to switch to dark mode."
    :type 'integer
    :group 'hesam)

  (defvar hesam-matugen--timer nil
    "Timer for the next sunrise/sunset switch.")

  (defun hesam-matugen--get-wallpaper ()
    "Return the current wallpaper path, or nil if unavailable."
    (let ((file (expand-file-name hesam-matugen-current-wallpaper-path)))
      (when (file-exists-p file)
        (with-temp-buffer
          (insert-file-contents file)
          (let ((wallpaper (string-trim (buffer-string))))
            (unless (string-empty-p wallpaper)
              (expand-file-name wallpaper)))))))

  (defun hesam-matugen--solar-times ()
    "Return (SUNRISE SUNSET) as decimal hours for today, with sunset offset applied."
    (require 'solar)
    (let* ((times (solar-sunrise-sunset (calendar-current-date)))
           (sunrise (caar times))
           (sunset (- (caadr times) (/ hesam-matugen-sunset-offset 60.0))))
      (list sunrise sunset)))

  (defun hesam-matugen--is-light-mode-p ()
    "Return non-nil if light mode should be active based on solar position."
    (let* ((times (hesam-matugen--solar-times))
           (sunrise (car times))
           (sunset (cadr times))
           (now (decode-time (current-time)))
           (current-hours (+ (decoded-time-hour now)
                             (/ (decoded-time-minute now) 60.0))))
      (and sunrise sunset
           (<= sunrise current-hours)
           (<= current-hours sunset))))

  (defun hesam-matugen--apply (state wallpaper)
    "Internal function to execute matugen for STATE and WALLPAPER."
    (start-process
     "matugen-process" nil
     "matugen" "image" (expand-file-name wallpaper)
     "-m" (symbol-name state)
     "--source-color-index" "0")
    (customize-save-variable 'hesam-matugen-darkmode-state state)
    (message "Matugen: set to %s using %s" state wallpaper))

  (defun hesam-matugen-apply (&optional state wallpaper)
    "Apply Matugen using optional STATE and WALLPAPER.
  Defaults to `hesam-matugen-darkmode-state` and saved wallpaper path."
    (when-let* ((chosen-state (or state hesam-matugen-darkmode-state))
                (chosen-wp (or wallpaper (hesam-matugen--get-wallpaper))))
      (hesam-matugen--apply chosen-state chosen-wp)))

  (defun hesam-matugen--get-system-state ()
    "Return current system theme state as `light' or `dark'."
    (let ((state (string-trim (shell-command-to-string "darkman get"))))
      (if (string-match-p "light" state) 'light 'dark)))

  (defun hesam-matugen-apply-by-solar ()
    "Apply Matugen based on whether it is currently daylight."
    (let ((target (if (hesam-matugen--is-light-mode-p) 'light 'dark)))
      (unless (eq target (hesam-matugen--get-system-state))
        (hesam-matugen-apply target))))

  (defun hesam-matugen--next-switch-time ()
    "Return seconds until the next sunrise or sunset."
    (let* ((times (hesam-matugen--solar-times))
           (sunrise (car times))
           (sunset (cadr times))
           (now (decode-time (current-time)))
           (current-hours (+ (decoded-time-hour now)
                             (/ (decoded-time-minute now) 60.0))))
      (cond
       ((< current-hours sunrise)
        (* (- sunrise current-hours) 3600))
       ((< current-hours sunset)
        (* (- sunset current-hours) 3600))
       (t
        ;; Past sunset — next event is tomorrow's sunrise
        (let* ((tomorrow (calendar-gregorian-from-absolute
                          (1+ (calendar-absolute-from-gregorian (calendar-current-date)))))
               (tomorrow-times (solar-sunrise-sunset tomorrow))
               (tomorrow-sunrise (caar tomorrow-times)))
          (* (+ (- 24 current-hours) tomorrow-sunrise) 3600))))))

  (defun hesam-matugen--start-timer ()
    (hesam-matugen--stop-timer)
    (let ((delay (hesam-matugen--next-switch-time)))
      (setq hesam-matugen--timer
            (run-with-timer delay nil #'hesam-matugen--on-switch))))

  (defun hesam-matugen--stop-timer ()
    (when (timerp hesam-matugen--timer)
      (cancel-timer hesam-matugen--timer)
      (setq hesam-matugen--timer nil)))

  (defun hesam-matugen--on-switch ()
    "Apply solar theme and schedule the next switch."
    (let ((target (if (hesam-matugen--is-light-mode-p) 'light 'dark)))
      (unless (eq target hesam-matugen-darkmode-state)
        (hesam-matugen-apply target)))
    (hesam-matugen--start-timer))

  (defun hesam-matugen--missing-deps ()
    "Signal an error if required external dependencies are missing."
    (unless (executable-find "matugen")
      (error "matugen not found"))
    (unless (executable-find "darkman")
      (error "darkman not found")))

  (defun hesam-matugen--enable ()
    "Enable `hesam-matugen-mode' internals."
    (hesam-matugen--missing-deps)
    (add-hook 'after-init-hook #'hesam-matugen--start-timer)
    (when after-init-time
      (hesam-matugen--start-timer))
    t)

  (defun hesam-matugen--disable ()
    "Disable `hesam-matugen-mode' internals."
    (remove-hook 'after-init-hook #'hesam-matugen--start-timer)
    (hesam-matugen--stop-timer))

  (defun hesam-matugen-toggle ()
    "Toggle Matugen theme mode."
    (interactive)
    (hesam-matugen-apply
     (if (eq hesam-matugen-darkmode-state 'dark) 'light 'dark)))

   ;;;###autoload
  (define-minor-mode hesam-matugen-mode
    "Toggle automatic Matugen integration."
    :global t
    :group 'hesam
    :lighter " Matugen"
    (if hesam-matugen-mode
        (hesam-matugen--enable)
      (hesam-matugen--disable)))

  ;; Off the startup path: this loads calendar/solar and shells out to
  ;; darkman, so do it once Emacs has been idle for a second.
  (use-package hesam-matugen
    :ensure nil
    :init
    (run-with-idle-timer 1 nil
                         (lambda ()
                           (hesam-matugen-mode)
                           (hesam-matugen-apply-by-solar))))
#+end_src

*** ef-theme switching
Pick the Ef theme closest to the wallpaper's colours. matugen renders
the template =~/.config/matugen/emacs.el= to =~/.emacs.d/matugen.el=, a
call to =hesam-matugen-pick-ef-theme-by-hsl= with the generated colours
as HSL strings. Its post hook loads that file through =emacsclient=.

The surface colour's lightness decides between light and dark themes.
Each Ef theme has an approximate hue/saturation anchor in
=hesam--matugen-ef-theme-targets=, and we choose the theme whose anchor
is closest to the primary colour. Hue is circular and weighted 2.5x
more than saturation, since hue is what makes a theme look like the
wallpaper.
#+begin_src emacs-lisp
  (require 'ef-themes)

  (defun hesam-matugen-pick-ef-theme-by-hsl (&rest colors)
    "Parse HSL COLORS `plist', pick an `ef-theme', save it, and load it."
    (let* ((parsed (hesam--matugen-parse-hsl-colors-plist colors))
           (primary (plist-get parsed :primary))
           (surface (plist-get parsed :surface)))
      (unless (and primary surface)
        (user-error "Missing required colors: :primary and :surface"))
      (let ((theme (hesam--matugen-pick-ef-theme-from-normalized parsed)))
        (unless theme
          (user-error "Could not determine theme from Matugen colors"))
        (customize-save-variable 'hesam-default-theme theme)
        (ef-themes-load-theme theme))))

  (defconst hesam--matugen-ef-theme-targets
    '((light
       ;; neutral / general
       (ef-light              :h 0.62 :s 0.20)
       (ef-deuteranopia-light :h 0.55 :s 0.20)
       (ef-tritanopia-light   :h 0.55 :s 0.20)

       ;; warm
       (ef-arbutus            :h 0.97 :s 0.55)
       (ef-summer             :h 0.93 :s 0.65)
       (ef-orange             :h 0.10 :s 0.85)
       (ef-day                :h 0.12 :s 0.45)
       (ef-eagle              :h 0.08 :s 0.25)
       (ef-reverie            :h 0.11 :s 0.25)
       (ef-melissa-light      :h 0.14 :s 0.55)

       ;; green / earthy
       (ef-spring             :h 0.36 :s 0.45)
       (ef-elea-light         :h 0.32 :s 0.35)
       (ef-cyprus             :h 0.14 :s 0.40)

       ;; cool
       (ef-duo-light          :h 0.58 :s 0.45)
       (ef-frost              :h 0.58 :s 0.45)
       (ef-maris-light        :h 0.54 :s 0.45)
       (ef-kassio             :h 0.78 :s 0.25)
       (ef-trio-light         :h 0.72 :s 0.35))

      (dark
       ;; neutral
       (ef-dark               :h 0.62 :s 0.30)
       (ef-deuteranopia-dark  :h 0.55 :s 0.20)
       (ef-tritanopia-dark    :h 0.55 :s 0.20)

       ;; warm / purple
       (ef-autumn             :h 0.08 :s 0.55)
       (ef-symbiosis          :h 0.14 :s 0.40)
       (ef-cherie             :h 0.90 :s 0.60)
       (ef-rosa               :h 0.94 :s 0.45)
       (ef-dream              :h 0.78 :s 0.25)
       (ef-winter             :h 0.82 :s 0.45)
       (ef-trio-dark          :h 0.76 :s 0.35)
       (ef-melissa-dark       :h 0.14 :s 0.55)

       ;; green
       (ef-bio                :h 0.38 :s 0.45)
       (ef-elea-dark          :h 0.30 :s 0.35)

       ;; cool / blue
       (ef-fig                :h 0.82 :s 0.30) ; fixed
       (ef-maris-dark         :h 0.56 :s 0.45)
       (ef-night              :h 0.62 :s 0.35)
       (ef-owl                :h 0.68 :s 0.20)
       (ef-duo-dark           :h 0.58 :s 0.45)))
    "Approximate hue/saturation anchors for Ef themes.")

  (defun hesam--matugen-pick-ef-theme-from-normalized (colors)
    "Pick the closest `ef-theme' from normalized COLORS plist.

  COLORS is a plist like:

    :primary (:h H :s S :l L)
    :surface (:h H :s S :l L)

  Return the chosen `ef-theme' symbol, or nil if required colors are
  missing."
    (let* ((primary (plist-get colors :primary))
           (surface (plist-get colors :surface)))
      (when (and primary surface)
        (let* ((h (plist-get primary :h))
               (s (plist-get primary :s))
               (surface-l (plist-get surface :l))
               (group (if (> surface-l 0.5) 'light 'dark))
               (themes (cdr (assq group hesam--matugen-ef-theme-targets))))
          (car
           (cl-reduce
            (lambda (a b)
              (if (< (hesam--matugen-theme-distance h s a)
                     (hesam--matugen-theme-distance h s b))
                  a
                b))
            themes))))))

  (defun hesam--matugen-theme-distance (h s theme-spec)
    "Return distance between wallpaper H/S and THEME-SPEC."
    (let ((theme-h (plist-get (cdr theme-spec) :h))
          (theme-s (plist-get (cdr theme-spec) :s)))
      (+ (* 2.5 (hesam--matugen-hue-distance h theme-h))
         (abs (- s theme-s)))))

  (defun hesam--matugen-hue-distance (a b)
    "Return circular distance between hue A and B, both in [0,1]."
    (let ((d (abs (- a b))))
      (min d (- 1.0 d))))

  (defun hesam--matugen-parse-hsl-colors-plist (colors)
    "Parse COLORS plist of HSL strings into normalized plist."
    (cl-loop for (key val) on colors by #'cddr
             when val
             for parsed = (hesam--matugen-parse-hsl val)
             when parsed
             collect key
             collect parsed))

  (defun hesam--matugen-parse-hsl (hsl-string)
    "Parse HSL-STRING into a plist (:h H :s S :l L), values in [0,1]."
    (when (and hsl-string
               (string-match
                "hsl(\\([0-9.]+\\),[[:space:]]*\\([0-9.]+\\)%,[[:space:]]*\\([0-9.]+\\)%\\(?:[[:space:]]*/[[:space:]]*[0-9.]+\\)?[[:space:]]*)"
                hsl-string))
      (list :h (/ (string-to-number (match-string 1 hsl-string)) 360.0)
            :s (/ (string-to-number (match-string 2 hsl-string)) 100.0)
            :l (/ (string-to-number (match-string 3 hsl-string)) 100.0))))
#+end_src

** flymake
Flymake is a built-in syntax checker for Emacs to be used everywhere,
but it's strongly linked to programming and that is why we define it

We check 0.25s after typing stops and on save, show the most severe

  (use-package flymake

** ghostel
Our main terminal: a terminal emulator built on =libghostty-vt=, the
terminal core of Ghostty. =C-x m= opens one, and in a project =C-x p m=
opens one in the project root. =ghostel-project= also replaces
=project-shell=. Terminals open at the bottom of the frame, using a
quarter of its height.

Inside the terminal:
- =C-s= searches the terminal buffer with =consult-line=.
- =C-k= kills to the end of the line in the shell and also saves the
  text to the kill ring.
- =M-p= / =M-n= send =C-p= / =C-n= to the shell, i.e. shell history.
- =M-s= is not sent to the terminal, so Emacs' search map keeps working.
The native module is downloaded automatically the first time ghostel
is used. URLs and =file:line= references in the output become links.
The shell may call =magit-status-setup-buffer= in Emacs through an
escape sequence, so a shell function can open Magit.
#+begin_src emacs-lisp
  (use-package ghostel
    :bind (("C-x m" . ghostel)
           :map ghostel-semi-char-mode-map
           ("C-s"  . consult-line)
           ("C-k"  . hesam--ghostel-send-C-k-and-kill)
           ("M-p" . (lambda () (interactive) (ghostel-send-key "p" "ctrl")))
           ("M-n" . (lambda () (interactive) (ghostel-send-key "n" "ctrl")))
           :map project-prefix-map
           ("m" . ghostel-project)
           ("M" . ghostel-project-list-buffers))
    :custom
    (ghostel-max-scrollback 10000)
    (ghostel-module-auto-install 'download)
    (ghostel-kill-buffer-on-exit t)
    (ghostel-enable-url-detection t)
    (ghostel-enable-file-detection t)
    :config
    (defun hesam--ghostel-send-C-k-and-kill ()
      "Send `C-k' to ghostel.
  Like normal Emacs `C-k'.  Kill to end of line and put content in kill-ring."
      (interactive)
      (kill-ring-save (point) (line-end-position))
      (ghostel-send-key "k" "ctrl"))
    (advice-add #'project-shell :override #'ghostel-project)
    (add-to-list 'project-switch-commands '(ghostel-project "Ghostel") t)
    (add-to-list 'project-switch-commands '(ghostel-project-list-buffers "Ghostel buffers") t)
    (add-to-list 'ghostel-eval-cmds '("magit-status-setup-buffer" magit-status-setup-buffer))
    (add-to-list 'ghostel-keymap-exceptions "M-s")
    (add-to-list 'display-buffer-alist
                 '("\\*ghostel.*"
                   (display-buffer-reuse-mode-window display-buffer-in-direction)
                   (mode . ghostel-mode)
                   (direction . below)
                   (window . root)
                   (window-height . 0.25))))
#+end_src

The custom function =hesam/vterm-project-shell= is for use with
=project.el=, as a replacement for =project-shell= (see the
commented-out lines above). It starts vterm in the project root, or
switches to that project's existing vterm buffer.
#+begin_src emacs-lisp
  (defun hesam/vterm-project-shell ()
    "Run `vterm' in the current project's root.

  If the VTerm buffer for this project exists and is visible, switch to it.
  If it exists but is not visible, pop a new window and switch to it.
  If the buffer does not exist, create a new one and switch to it.
  A numeric prefix argument ARG does two things:
  - If a buffer associated with the prefix exists, switch to that buffer accordingly.
  - Otherwise, create a new buffer with the prefix number in the name."
    (interactive)
    (if (fboundp 'project-root)
        (let* ((root (project-root (project-current t)))
               (dir-name (file-name-nondirectory (directory-file-name root)))
               (prefix-arg (if current-prefix-arg (format "<%d>"current-prefix-arg) ""))
               (buffer-name (format "*%s*%s" (concat dir-name " vterm") prefix-arg))
               (existing-buffer (get-buffer buffer-name)))
          (if existing-buffer
              (pop-to-buffer existing-buffer)
            (let ((new-buffer (vterm-other-window buffer-name)))
              (with-current-buffer new-buffer
                (vterm-send-string (concat "cd " root))
                (vterm-send-return)
                (vterm-send-C-l)))))))
#+end_src
